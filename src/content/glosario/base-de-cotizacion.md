La base de cotización es la cifra sobre la que se calculan cada mes las cotizaciones a la Seguridad Social: se multiplica por unos porcentajes fijados por ley y el resultado es lo que se paga. Tiene un mínimo y un máximo que se actualizan cada año.

Para un trabajador por cuenta ajena, la base sale de su salario mensual, con la parte proporcional de las pagas extra, y aparece en la nómina. Para un autónomo, depende de sus rendimientos netos: según lo que gana se le asigna un tramo, y dentro de ese tramo elige una base entre la mínima y la máxima.

La base de cotización importa también para el futuro: las prestaciones, como la baja por enfermedad, el paro o la jubilación, se calculan a partir de lo cotizado. Una base más alta supone pagar más hoy y tener más protección después.
